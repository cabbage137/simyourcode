# SimYourCode

A free, unofficial practice simulator for the 2026-2027 FIRST Tech Challenge game BIOBUZZ. Build a robot, write Java or Blocks code, and drive a full match in the browser.

Live site: https://cabbage67.github.io/simyourcode/

Founded by Bruno, Team 18629 - Hydra. (c) 2026, all rights reserved. Not affiliated with or endorsed by FIRST.

The site is plain HTML, CSS and JavaScript with no build step: open `index.html` through any web server.
